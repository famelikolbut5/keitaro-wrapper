# Keitaro Wrapper

Создаёт кампании и редактирует офферы в потоках Keitaro. FastAPI, SQLAlchemy, Alembic, SQLite, Jinja и HTMX.

## Запуск

Установите Python 3.12 или новее. Выполните в PowerShell из папки проекта.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install .
Copy-Item .env.example .env
```

Войдите в [эмулятор Keitaro](https://keitaro-for-tests.etolegko.com/admin/) через GitHub и нажмите **API ключ**. Вставьте ключ в `KEITARO_API_KEY` в файле `.env`. Укажите свою фамилию в `CAMPAIGN_PREFIX`, например `test_ivanov_`. Редактор сам добавит префикс к названию кампании.

Адрес эмулятора уже указан в `.env.example`. Для перехода со старого стенда обновите `KEITARO_URL` и ключ в своём `.env`. Укажите `DATABASE_URL=sqlite:///keitaro-emulator.db`, чтобы хранить черновики нового стенда отдельно.

```powershell
.\.venv\Scripts\python run.py
```

Откройте [редактор](http://127.0.0.1:8000). В Linux и macOS используйте `python3 -m venv .venv`, `cp .env.example .env` и интерпретатор `.venv/bin/python`.

## Миграции

`run.py` применяет миграции Alembic перед запуском и создаёт `keitaro.db`. Чтобы применить их отдельно, выполните команду.

```powershell
.\.venv\Scripts\python -m alembic upgrade head
```

## Работа с кампаниями

1. Нажмите **Новая кампания**. Укажите название, код страны, оффер, домен, группу и источник.
2. Поток для выбранной страны перенаправляет на Google. Остальной трафик попадает в поток с офферами.
3. Введите ID существующей тестовой кампании и нажмите **Открыть**. Добавьте, уберите или верните оффер из архива. Закрепите долю, чтобы сохранить её при пересчёте.
4. Нажмите **Опубликовать**, чтобы отправить правки в Keitaro, или **Отменить**, чтобы вернуть исходные значения.

В учебном эмуляторе проверяйте маршруты по настройкам потоков в админке. Стенд не выполняет переходы по ссылкам кампаний и не собирает статистику кликов.

Чтобы получить изменения из Keitaro, снова нажмите **Открыть** или обновите страницу. Ранее загруженные офферы, удалённые в Keitaro, появятся в архиве. Если сумма долей активных офферов отличается от 100%, редактор предложит черновик с пересчётом.
